# Tiny Soho motion runtime

This repository is a workspace for directing Tiny Soho slides into short reel clips. For any job, follow
`.claude/skills/tiny-soho-direct/SKILL.md`.

- Never push to `main`. Runs push only to `claude/run-*` branches, and only the files the routine prompt lists.
- Never use connectors or MCP tools, and never use the network except for `setup.sh` and `git push`.
- The images are children's photos. Do not copy them anywhere outside this repository.
